# Customer Database Project

## Overview
A relational database project designed to manage customer profiles and organize data efficiently. This project was developed to demonstrate foundational skills in database management and SQL.

## Features
- Stores customer details (ID, Name, Address, Phone Number).
- Built using relational database principles.
- Includes SQL scripts for creating tables and inserting sample data.

## Tools Used
- **MySQL**
- **MySQL Workbench**
- **SQL** (CREATE, INSERT, SELECT statements)

## How to Use
You can run the SQL scripts in the `customer_db.sql` file using MySQL Workbench to create the database and test the queries.
